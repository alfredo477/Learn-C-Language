//文件的意义：让程序的数据保存下去(避免数据丢失，程序结束后数据消失)
//           除了文件还有数据库(MySQL) 都可以持久化存储文件
//内存(random access memory)：临时存储(程序一结束，释放内存空间，数据消失)
//操作系统：以文件为处理单位，无论存储还是读取都要在文件中进行
//数据流：数据流是数据在程序中流动的过程，数据流的方向有两种：输入流和输出流 从源头到目的地的流动过程
//文件缓冲区：从程序到磁盘之间读取或写入数据时，为了提高文件操作的效率，系统会在内存中开辟一块区域作为文件缓冲区，用于暂存数据
//文件信息区：文件信息区是操作系统为每个打开的文件维护的一块内存区域，里面保存了文件的各种信息，如文件名、文件大小、文件位置指针等
//           这些信息被系统声明为一个结构体 FILE，文件信息区的地址就是文件指针
//FILE：struct _iobuf { ... }，文件信息区的结构体类型 但是微软为了兼容C语言标准，使用typedef将struct _iobuf重命名为FILE
